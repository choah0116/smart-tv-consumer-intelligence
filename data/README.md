# Data

Large processed data files are not included in this repository.

This project uses the Amazon Reviews 2023 dataset from McAuley Lab, including
product metadata and consumer reviews for Smart TVs from Samsung, LG, Sony,
TCL, and Hisense.

The final analytical sample contains 1,097 Smart TV products and 111,191
consumer reviews covering the 2015–2023 analytical period.

See the main project README and data collection notebook for details on data
collection, filtering, and preprocessing.
